# lab-exam-agent

Transpilador que converte uma especificação JSON de agente em código Python com Google ADK.
O agente gerado lê um pedido médico fictício (OCR via MCP), resolve os exames em um catálogo
(RAG via MCP) e registra a solicitação de agendamento em uma API FastAPI.
